\# 🛡️ Fact Forge: Advanced Misinformation Detection



\## 📖 Project Overview

Fact Forge is an end-to-end AI system designed to classify news articles as \*\*Real\*\* or \*\*Fake\*\*. The core of the system is built on \*\*DeBERTa-v3-Small\*\*, fine-tuned on the \*\*WELFake dataset\*\* (72,000+ articles).



\## 🚀 Key Features

\- \*\*Neural Engine:\*\* Powered by Microsoft's DeBERTa-v3 with Disentangled Attention.

\- \*\*Robust Regularization:\*\* Uses high Dropout (0.5) and Weight Decay (0.2) to ensure generalization.

\- \*\*Nuclear Preprocessing:\*\* Custom cleaning pipeline to remove dates and temporal bias.

\- \*\*Performance:\*\* Achieved \*\*95.6% Accuracy\*\* on the validation set.



\## 🛠️ Project Structure

\- `backend/`: Contains the AI training script (`train\_model.py`) and model logic.

\- `frontend/`: (Work in Progress) React-based user interface.



\## ⚙️ Tech Stack

\- \*\*Language:\*\* Python 3.10+

\- \*\*Deep Learning:\*\* PyTorch, HuggingFace Transformers.

\- \*\*Data Science:\*\* Pandas, NumPy, Scikit-learn.
